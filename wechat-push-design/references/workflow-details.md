# 工作流详细话术与检查清单

## 阶段一：素材盘点与设计规划

### 收到输入后必做

1. 逐项清点用户给了什么：
   - 文案：字数、段落数、有无标题层级
   - 图片：数量、内容（产品/人物/场景）、清晰度
   - 模板/参考：风格倾向、可复用的结构
2. 判断内容类型：品牌宣传 / 活动推广 / 产品发布 / 知识干货 / 企业公告 → 决定节奏型。

### 设计规划输出模板

```markdown
## 📋 素材盘点
- 文案：X 段，约 X 字（主标题 / 引言 / 正文 X 节 / 结尾）
- 图片：X 张（内容描述）
- 参考模板：有无

## 🎯 设计规划
- 内容结构：1. ... 2. ... 3. ...
- 风格提案：<一句话调性>，理由：...
- 素材使用计划：图 1 用于首屏氛围；图 2 用于第 2 节配图...

## ⚠️ 需要你确认/补充
1. 缺失：<如品牌 LOGO、二维码、品牌色>
2. 建议修改：<如第 3 段 200 字偏长，建议精简至 80 字>
```

### 常见问题预设（主动检查）

- 文案是否过长？单屏超过 150 字的段落建议拆分。
- 有无明确的行动号召（关注/购买/报名）？没有则建议补充。
- 图片是否够用？长文建议每 2–3 屏一张图，不够则规划 SVG 装饰补足。

## 阶段二：设计语言确认

### 输出模板

```markdown
## 🎨 设计语言方案 A：<风格名>
- 主色 #XXXXXX / 辅色 #XXXXXX / 强调色 #XXXXXX
- 背景 #XXXXXX / 文字 #XXXXXX
- 标题：字重 700，44–56px，letter-spacing 4px
- 正文：字重 400，30px，行高 1.9
- 装饰语言：<细线 + 大号序号 / 几何色块 / 渐变圆 ...>
- 参考气质：<如 Kinfolk 杂志 / 苹果官网 / 国风茶室>
```

给 1–2 套即可，不要超过 2 套（选择困难）。用户说「你定」时，选最贴合内容调性的一套并说明理由。

## 阶段四：预览检查清单

截图给用户前自查：

- [ ] 首屏是否有视觉钩子（大图/大标题/色块）
- [ ] 滚动节奏是否流畅，无大片无装饰的纯文字墙
- [ ] 所有图片正常加载
- [ ] 结尾有明确收尾（CTA / 落款 / 二维码占位）

## 阶段五：导出操作指引（desktop_browser MCP，已验证）

完整步骤见 `SKILL.md` 阶段五。要点：

1. 本地起静态服务器（MCP 不支持 file://）：
   `python -m http.server 8321 --directory <推送文件夹>`
2. `tab.set_device_mode`：responsive，宽 750，scaleMode=fixed，scale=1 → 自动 DPR=2。
3. 先设偏大视口高度测量内容底部，再设精确高度重截。
4. `page.visual.snapshot` + `page.visual.crop` 分带裁切（带高 ≤800 显示像素），
   crop 输出即原始分辨率（1500px 宽）。
5. `python scripts/stitch_png.py long-image.png band*.png` 零依赖拼接。
6. ReadMediaFile region 抽查接缝与文字清晰度。

导出失败时的降级：分段裁切图直接逐张交付，并告知用户可自行拼接。

## 与用户沟通的原则

- 每次确认请求只问关键问题，一次不超过 3 个。
- 用户给的修改意见要逐条落实并复述确认结果。
- 保持设计师口吻：解释「为什么这样设计」，而不只是「做了什么」。
